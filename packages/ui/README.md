## 入口与组件

`LibraryApp` 提供设备、游戏、设置三页以及游戏操作面板、目录设置、传输预览和任务结果。桌面使用 antd，Android 使用 antd-mobile 导航/弹层并复用 antd 的紧凑输入、表格和对话框；图标来自 `@ant-design/icons`。

## 平台适配

`UiAdapter` 只传公开目录元数据、游戏/设备配置及任务状态；平台实现负责存储、原生目录选择、连接、服务与传输。所有失败由 Promise 抛出并在界面显示。`DirectoryPane` 独立读取一列当前层目录，失效后清除本次选择；界面不读取文件内容。应用入口持有稳定的适配器实例，轮询在切到后台时暂停，既有原生任务继续。

## 当前功能

本机游戏目录与多设备关联自动保存，首期同时只连接一台设备。设备地址统一完整 HTTP URL，支持只读显示与复制；目录选择使用 `Space.Compact`。两端文件始终并列，显示分钟级修改时间，文件条目直接显示元数据。目录变更和传输目的地由用户明确选择。

传输复用 M-001 的独立测试目录新文件发布。覆盖、镜像删除和备份恢复按后续里程碑接入；相关界面明确显示可用状态，避免将原型样例当作实际文件结果。
