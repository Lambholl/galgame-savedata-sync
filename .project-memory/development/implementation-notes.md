| 开屏圆形遮罩与角色退出 | 第一次眨眼在 200ms 结束时开始扩大圆形遮罩，到 700ms 覆盖窗口，头像的屏幕位置和比例保持不变。立绘为 bs2_sp1_base13.png，底部自然超出屏幕。第二次眨眼在 550ms 结束时背景开始淡出，遮罩结束后停 250ms，角色在 950–1350ms 保持不透明向下滑出，头顶越过窗口底边时背景正好全透明。遮罩和下滑都在各自前 30% 的时间里从零匀加速，之后匀速，位置与速度连续。完整立绘配准到头像后缩为 444×960，无损 WebP 为 213066 字节；圆内保留睁眼帧的像素，圆边按 648px 逻辑坐标与立绘做两像素混合。运行时使用系统预绘制网格，只生成一份身体位图，再叠加五帧的眼睛局部（648px 逻辑坐标 x218–428、y313–395）。六张素材合计 541204 字节 | Android LaunchAnimation.java、drawable-nodpi/splash_portrait.webp |
| 开屏头像像素边缘 | Android 12+ 的系统开屏先在框架 starting_surface_default_icon_size 的画布预绘制，前景中心和半宽使用整数截断，然后把位图放大到实际图标尺寸。五张帧图按同一流程预绘制并复用位图，切换前后头像宽度一致；设备框架资源用于适配厂商覆盖值，取不到时使用 108dp。旧版 Android 使用 2/3 圆形裁切 | Android LaunchAnimation.java |
| Android 眨眼开屏 | 系统启动图为 splash_open.webp。应用首帧前先准备原生头像覆盖层；系统开屏退出时立即移除系统副本，等网页首屏或启动错误提示通过 LaunchAnimation.ready 和 WebView 可绘制回调后，再按 open、slight、half、near、closed、near、half、slight、open 的顺序播放两次眨眼动画。每帧 25ms，两次间隔 150ms，整段 550ms。后续遮罩、背景和角色退出见“开屏圆形遮罩与角色退出”。转后台时清理覆盖层，系统关闭动画效果时跳过播放；点按可跳过整个动画，5 秒后移除覆盖层。从后台返回（onRestart）和 Activity 重建都新建 LaunchAnimation 再播放一次：系统开屏不一定出现，所以不等退出回调，也不等系统的窗口切换动画结束，第一次绘制时就开始眨眼，平板上约 100ms；网页首屏没就绪时继续等 ready。离开后很快返回时 Activity 还没收到 onStop，只走 onPause 和 onResume，不播放；平板上间隔不超过 0.4 秒不播放，0.7 秒起播放。应用自己打开文件夹选择器时，MainActivity.startActivityForResult 留下标记，从选择器返回不播放；选择器期间 Activity 被重建时标记丢失，会播放。系统从后台恢复窗口时会先显示任务快照，Android 13+ 用 setRecentsScreenshotEnabled(false) 关闭，最近任务里因此不保存页面缩略图；Android 10–12 没有这个接口，快照不受影响。WebView 低于 140 时 Capacitor 给 DecorView 添加系统栏边距，系统开屏头像副本会随之下移，所以开屏期间先把同一份边距移到 android.R.id.content，布局未完成时跳过该帧，退出后再恢复。五张帧图由原始 keyframes 图统一缩为 444×444，按与立绘一致的比例绘制，用无损 WebP 编码，合计 328138 字节 | mobile MainActivity、LaunchAnimation.java、LaunchAnimationPlugin.java、platform/launch-animation.ts、main.tsx、styles.xml、drawable-nodpi/splash_*.webp |
