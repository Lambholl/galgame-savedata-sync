# 已知问题

记录已经发生、仍未解决且会影响后续工作的缺陷和阻碍；还没发生的写在[风险登记表](risks.md)。解决后将长期结论吸收到当前文档并删除对应行。

| ID | 问题 | 影响 | 临时方案 | 状态 |
| --- | --- | --- | --- | --- |
| BUG-009 | Windows 写入途中进程被强杀、崩溃或断电时，存档目录里留下 `.savedata-copy-*.tmp` 或 `.savedata-new-*.tmp`：候选文件写在目标文件的同一目录（`sync-target-files.ts`、`new-file-publisher.ts`），两端扫描都不跳过这两个前缀 | 下次比较时残留文件算作存档文件，从电脑传到另一台设备时会被复制过去 | 手动删除；或者从另一台设备传回电脑时选“删除目标多出的条目” | open，M-004 修复 |
| BUG-010 | Android 连点“连接”时，连上后、控制通道打开前的一瞬按钮还能点，会再触发一次连接 | 多一次连接请求，提示可能重复 | 连上前不要连点 | open，M-004 修复 |
| BUG-011 | 游戏目录授权失效后恢复，要断开重连才不再报授权失效，点刷新没用 | 目录已恢复仍不能比较和传输 | 断开后重新连接 | open，M-004 修复 |
| BUG-012 | Android 发起移动端到电脑的传输，完成后点“重新扫描”，方向回到默认的电脑到本机 | 用户不注意就会反方向比较 | 重新扫描前手动翻转方向 | open，M-004 修复 |
| BUG-013 | 游戏移除后，任务条还留着一条名为“未知”的记录 | 任务条显示无效记录 | 无 | open，M-004 修复 |
| BUG-014 | 电脑备份页开着时，对方传入完成后备份列表不刷新 | 新备份要离开再进入备份页才显示 | 重新进入备份页 | open，M-004 修复 |
| BUG-015 | Android Activity 重建后，游戏页约 0.2 秒显示“未连接设备 / 未知”，详情页约 1.5 秒显示“未知 · 未知”，配置读到后恢复 | 短暂显示错误状态 | 无 | open，M-004 修复 |
| BUG-016 | Android 重新选择游戏目录后 rootId 变化，旧目录的备份不再列出，也不参与轮换 | 旧备份只能在文件管理器里手动删除，也不能从界面恢复 | 手动删除旧备份 | open，改不改待维护者决定 |
