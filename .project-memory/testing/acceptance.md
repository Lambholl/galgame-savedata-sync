# 验收标准

1 GiB 传输基线见仓库根目录的 `docs/validation/m001-resources.md`。

覆盖复制、默认备份、保留份数及手工恢复按[工作包登记](../development/work-packages.md)和仓库根目录的 `docs/plans/m002-sync-copy.md` 第 6 节验收，结论、支持范围和真实存档开放范围也在该节。异常规则见该文档第 3 节；当前状态如下。

| 功能 | 验收条件 | 测试方式 | 状态 |
| --- | --- | --- | --- |
| 平台与目录授权 | Windows 与 Android 10 及较新系统可运行，授权目录可读写；应用重启后恢复有效目录授权 | 真机与桌面集成验证 | passed |
| 明文 HTTP | 在无 TLS、证书和加密配置的局域网完成连接、控制与文件往返 | 网络与集成验证 | passed |
| 方向选择 | 明确选择电脑 → Android 或 Android → 电脑后，内容按该方向应用；修改日期较新的一端不影响方向 | 双向场景验证 | passed |
| 当前状态独立 | 两端当前文件、方向和模式相同时，先前未同步、不同方向同步或不同同步次数均得到相同计划；不存在历史基线依赖 | 实际场景与集成验证 | passed |
| 配置保持 | 重启应用或手动更新设备 IP，项目与目录映射仍存在；地址属于另一设备时提示重新关联 | 场景验证 | passed |
| 发现与 DHCP 重连 | 首次连接提供发现列表和手动 IP；更改 Windows 或 Android 地址后通过 mDNS/DNS-SD 重新发现并连接，发现不可用时通过手动改址完成，原目录配置保留 | 手动改址与配置保持已验证；自动发现属于 M-003 | partial |
| 文件与文件夹预览 | 两端条目可浏览、展开；文件显示实际大小和修改日期，文件夹显示可获得的自身日期；未知属性与不存在明确区分 | 界面与提供者验证 | passed |
| 不统计文件夹大小 | 打开、展开、刷新预览不为文件夹大小做递归汇总；文件夹大小显示“—”等非汇总值。同步所需递归枚举仍正常工作 | 扫描适配器调用验证及大目录人工验证 | partial |
| 当前内容比较 | 同路径同大小但内容不同的文件标为不同；日期不同但内容相同可跳过，日期不决定权威端 | 针对性集成验证 | passed |
| 复制与删除规则 | 默认覆盖复制，保留目标独有条目；用户主动选择镜像时预览并确认删除，目标最终匹配源；不可读源返回读取失败，空目录单独表示 | M-002 验收覆盖复制、不可读源与空目录；M-004 验收镜像删除 | partial |
| 失败处理 | 断网、存储不足、授权失效、文件传输期间变化时结果明确；重连重新扫描，临时接收文件与已完成文件分开标记 | 真机与注入：断网、手机存储不足、两端目录失效、传输期间变化、结果待确认已通过；电脑存储不足未跑 | partial |
| 备份 | 默认开启且可关闭，在目标端独立备份区按份数保留（默认 3 份）；可手工恢复，备份不进入同步目录或影响同步判定 | Android 13 真机合成目录（含备份移到 `Android/data` 后）和 Windows 本机复核通过；M-004 补删除前备份。M-002 不做 Android 10 实测 | partial |
| 通知保持与两端操作 | Android 业务不判断前后台；仅传输验收持续通知/dataSync 保活、Activity 重连及完成/显式取消后清理；普通目录、扫描、连接和查询的后台成败不设验收要求；两端都能发起 | 两端发起、回桌面继续、通知、取消和真实 Activity 重建（开启“不保留活动”）已真机通过 | passed |
