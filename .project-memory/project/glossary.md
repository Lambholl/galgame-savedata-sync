# 项目术语表

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| 用户 | 应用的使用者 | 不指项目维护者 |
| 维护者 | 决定需求、验收和 Git 操作的项目负责人 | 文档里流程上的确认、验收和待决定都由维护者做出，不能由执行者自己给出；不含应用界面里的确认操作 |
| 移动端 | 运行 Android 应用的设备，包括手机和平板；与“桌面端”相对 | 界面文案：zh-TW“行動端”，en-US“mobile device”或“Mobile”，ja-JP“モバイル端末”或“モバイル”。只有说具体硬件时才写手机或平板 |
| 桌面端 | 运行 Windows 或 Linux 版应用的设备；与“移动端”相对 | 代码里的 desktop。讲版本、界面和实现时写桌面端，讲实物设备时写“电脑”，如“电脑和手机在同一局域网”；不写“电脑端”。单独的“桌面”指操作系统的桌面环境，如“Linux 桌面”“桌面门户” |
| 监听方 | 连接中运行 HTTP 服务和控制通道、广播并显示连接二维码的一端 | 与平台无关（[ADR-0004](../decisions/ADR-0004-symmetric-listener-dialer-roles.md)）；代码里的 listener。电脑和 Android 都能担任 |
| 拨号方 | 连接中主动连接对方、编排扫描、计划和任务的一端 | 与平台无关；代码里的 dialer。监听方发起的传输经控制通道交给拨号方执行。当前 Android 和电脑都能担任 |
| 本机服务 | 设备作为监听方运行的服务，界面上的“本机服务” | Android 上开着时由前台服务和常驻通知保持，应用退到后台或 Activity 销毁都不停止 |
| 界面用语 | 两端入口和页面统一叫“游戏设置”“传输详情”“传输计划”，动作动词统一用“传输”；“移除”游戏删除它的配置、设备关联和备份，不删存档文件 | 四种语言的文案在 `apps/shared`；后端错误原文用英文，界面按错误码翻译 |
| 复制任务 | 按计划覆盖、新建或删除文件的传输任务，状态是 `SyncJobState` | 桌面端 `DesktopSyncRegistry`，移动端 `SyncTransferEngine` |
| 目录表 | 设备之间交换的游戏和目录列表 | 代码里的 catalog |
| 封面 | 游戏卡片上显示的竖版图片 | 代码里的 poster；界面文案：en-US“Poster”，ja-JP“ポスター”，zh-TW“封面”。不用 cover 和“カバー” |
| 轮次 | 一份备份 | 代码里的 round |
| 名额 | 进程内同一时刻只允许一个复制任务或恢复运行的互斥，从接受任务占到清理结束 | `TargetOperation`；归档缓存和文件发布各有自己的名额 |
| 候选文件 | 写入目标目录前的临时文件，字节数核对通过后才变成最终文件 | 代码里的 candidate |
| 发布 | 把核对过的候选文件变成目标目录里的最终文件 | 代码里的 publish |
| 残留 | 未提交、未清理完的备份轮次、缓存或候选文件 | 代码里的 incomplete、cleanup、residual |
