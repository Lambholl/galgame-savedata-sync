# 项目范围

## 目录

- [1. 范围内](#1-范围内)
- [2. 范围外](#2-范围外)

## 1. 范围内

| 项目 | 说明 |
| --- | --- |
| 平台和网络 | Windows、Android 10 及以上、局域网、两端在线、明文 HTTP |
| 核心同步 | 保存目录映射，用户手选方向，仅比较当前文件 |
| 文件预览 | 两端条目、目录层级、文件大小与修改日期；不统计文件夹递归大小 |
| 地址变更 | 重新发现或手动改 IP 后保留原目录配置 |
| 技术栈 | React + TypeScript + Vite；Windows Electron + antd；Android Capacitor + antd-mobile |
| 连接与发现 | 首版发现列表 + 手动 IP，mDNS/DNS-SD 自动发现和地址变化重连 |
| 两端操作 | 两端连接时均可发起同步，Android 不以界面可见性判断操作可用性 |
| 复制模式 | 覆盖复制和镜像同步，默认覆盖复制；镜像执行前预览删除项 |
| 备份 | 提供开关、默认开启、保留最近 3 次，目标端独立备份区可手工恢复 |

## 2. 范围外

| 项目 | 原因 |
| --- | --- |
| TLS、证书和数据加密 | 用户明确排除 |
| 自动判断同步方向、历史共同基线、历史增量索引 | 用户要求只根据当前状态且手选方向 |
| 文件夹递归大小汇总 | 文件夹不递归计算大小；修改日期采用条目本身的当前元数据 |
| 游戏识别、引擎适配、存档转换与内容语义合并 | 工具定位为文件夹同步器 |
| 公网中转、异地同步和 NAS 后端 | 不属于首版局域网双端范围 |
| 文件内容解析、存档编辑器 | 当前预览需求为目录与属性对照 |
| Android 后台自动同步、定时任务及开机保活 | 当前只保持用户已发起的活动传输，使用持续通知的前台服务；不自动创建任务或重放旧传输 |
| 首版扫码与配对码 | 首版使用发现列表和手动 IP；扫码后续补充 |
